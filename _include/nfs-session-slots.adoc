NFS-Session-Slots sind das NFSv4.X-Äquivalent zu den Slot-Tabellen von NFSv3. Der Standardwert ist üblicherweise 64. Ein Wert von 180 ist optimal, da er dem Session-Limit in ONTAP entspricht.

Beispiel für die Festlegung des Parameters max_session_slots:

....
# cat /etc/modprobe.d/nfsclient.conf
 options nfs max_session_slots=180
....
Dieser Parameter wird von einem Kernelmodul verwendet, das beim Systemstart geladen wird. Im Gegensatz zum NFSv3-Slottabellenparameter ist er nicht dynamisch. Ein Neustart ist erforderlich, damit die Änderung wirksam wird.


CAUTION: Wenn diese Parameter nicht festgelegt werden, kann dies erhebliche Auswirkungen auf die Performance haben. Die Performance kann erheblich eingeschränkt sein, da das Linux-Betriebssystem nicht genügend E/A-Operationen ausführt.
