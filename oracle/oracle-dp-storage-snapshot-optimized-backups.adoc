= Storage Snapshot optimierte Backups
:allow-uri-read: 


[role="lead"]
Oracle Snapshot Optimized Backups war eine Methode der zeitpunktgenauen Wiederherstellung, die es dem Benutzer ermöglichte, eine Wiederherstellung mithilfe von Snapshots durchzuführen, ohne die Datenbank in den Hot Backup-Modus zu versetzen.

Die Wiederherstellung aus Snapshots ist auch ohne Backup-Modus möglich, allerdings wird nur die vollständige Wiederherstellung mit RECOVERY AUTOMATIC unterstützt. Eine unvollständige Wiederherstellung ist mit der Methode SNAPSHOT TIME möglich, um den Erstellungszeitpunkt des Snapshots anzugeben.
